# 日本株対応スクリーナー検証結果 (Japanese Stock Screener Verification)

このリポジトリのスクリーナーを日本株に対応させる検証を行いました。

## 概要

`yfinance` ライブラリを使用することで、日本株（例: `7203.T`）の株価データ、財務データ、企業情報を取得し、IBD（Investor's Business Daily）スタイルのスクリーニングロジックを適用できることが確認できました。

## 検証用スクリプト

`jp_stock_screener.py` を作成しました。これは `yfinance` を使用して、指定された日本株リストに対して6つのスクリーニングを実行します。

### 実行方法

```bash
pip install -r requirements.txt
python jp_stock_screener.py
```

※ `requirements.txt` に `yfinance` `curl_cffi` `pandas` `numpy` が必要です。

## スクリーナーの対応状況

検証の結果、6つのスクリーナー全てについて、データの入手元を `yfinance` に切り替えることで日本株への対応が可能でした。

| スクリーナー名 | 日本株対応 | 必要なデータ | 備考 |
|---|---|---|---|
| **Momentum 97** | ⭕ 可能 | 株価履歴 (OHLCV) | 過去1ヶ月、3ヶ月、6ヶ月の株価変動率から計算可能。 |
| **Explosive Estimated EPS Growth** | ⭕ 可能 | 四半期EPS | `yfinance` の `quarterly_financials` からBasic EPSが取得可能。予想EPS(Estimated)は無料版では取得が難しい場合があるため、実績EPSの急成長で代用可能。 |
| **Up on Volume List** | ⭕ 可能 | 株価、出来高 | 価格上昇かつ出来高急増（移動平均比）の判定が可能。 |
| **Top 2% RS Rating List** | ⭕ 可能 | 株価、セクター | 相対強度(RS)は、日経平均(`^N225`)やTOPIXをベンチマークとして計算可能。セクター情報も取得可能。 |
| **4% Bullish Yesterday** | ⭕ 可能 | 株価、出来高 | 前日比4%以上の上昇などを判定可能。 |
| **Healthy Chart Watch List** | ⭕ 可能 | 移動平均線、RS | 10, 21, 50, 200日移動平均線の配列（パーフェクトオーダー）の判定が可能。 |

## 今後の実装に向けた注意点

1.  **データ取得制限**: `yfinance` はスクレイピングベースのため、大量の銘柄（全上場銘柄約4000社など）を一気に取得しようとするとブロックされる可能性があります。`curl_cffi`の使用や、適切な待機時間(sleep)の設定が必要です。
2.  **財務データの精度**: 米国株に比べ、日本株の財務データ（特に予想EPSなどの詳細データ）は `yfinance` では一部欠損している場合があります。より厳密なファンダメンタルズ分析を行う場合は、専用のAPI（例: Yahoo Finance Japanを直接解析、または有料API）の検討が必要かもしれません。
3.  **ティッカーシンボル**: 日本株は証券コードに `.T` を付与する必要があります（例: トヨタ自動車 → `7203.T`）。

## 結論

**日本株専用スクリーナーへの改修は可能です。**
`jp_stock_screener.py` はそのProof of Concept（概念実証）として機能しており、これを拡張して全銘柄を対象にすることで、実用的な日本株スクリーナーとして運用できます。
